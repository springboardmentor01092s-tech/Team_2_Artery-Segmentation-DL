# Additional design previews

Editorial preview collection updated on 15 October 2026, awaiting user approval.

- Editorial Focus: `/?design=editorial` — restrained slate palette, serif display
  headings, flat study panel, dividing rules and continuous statistical rows.
- Journal: `/?design=journal` — ink-and-white styling, bold serif headings,
  strong horizontal rules and restrained sections.
- Paper: `/?design=paper` — warm paper surfaces, report-like hero, italic section
  headings and individually spaced statistical cards.
- Atlas: `/?design=atlas` — structured blue research layout, side annotation
  panel, monospaced statistics and blue section rules.

Clinical Teal and Midnight Workstation were removed at the user's request.
Their old preview query values now fall back to the existing design.

The existing and Apple-inspired previews remain available. Default remains
existing. Alternate previews share the isolated layout foundation and the same
real account, permissions, case data and preprocessing features. No fake metrics
or findings, authentication bypass, training or GPU workload was introduced.

UI/UX skill guidance informed readable text, spacing/reflow, semantic roles,
focus indicators and reduced-motion behavior. No new font or package downloads.
All three new signed-in desktop dashboards were opened in separate Chrome tabs and
visually inspected. TypeScript and Vite build passed. Mobile, 200% zoom and full
accessibility testing are not yet verified. Bundle-size advisory remains.
