# Qca reference availability

No exact-frame QCA reference was established in the audited releases. CARDIAG's author reported no QCA or reference lumen diameters. AngioCAD workbook headers describe series and segment labels without matched minimum/reference lumen and calibration fields. [CathAI](https://pmc.ncbi.nlm.nih.gov/articles/PMC10421915/) describes clinical-care data that are not publicly available. See the [dataset audit](PUBLIC_REFERENCE_DATASET_AUDIT.md) for release identifiers and the metadata inspection method.

Acceptance requires paired de-identified case/frame/lesion IDs, reviewable calibration, minimum and reference lumen measurements, and provenance for the measurement procedure.
