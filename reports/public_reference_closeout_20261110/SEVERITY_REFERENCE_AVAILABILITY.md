# Severity reference availability

The reviewed measurement workflow in `frontend/src/StenosisMeasurements.tsx` requires a protocol and calibration evidence and displays unavailable when reviewed measurements are absent. The narrowing and measurement tests passed in the [focused software suite](SYNTHETIC_VESSEL_GEOMETRY_RESULTS.md).

CADICA categories and AngioCAD segment labels are candidates for source-label agreement on appropriately matched samples. A clinical severity evaluation needs independent lesion-level grades and an approved grading protocol, or matched QCA measurements with validated conversion criteria. No clinical severity score is available.
