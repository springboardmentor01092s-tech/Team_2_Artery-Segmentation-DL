# Automatic diameter agreement

No automatic real-image agreement result is available.

The current CoroVision geometry output contains predicted-mask width profiles. It does not provide a validated candidate-local MLD plus independently selected RVD. The 20-frame package has zero independent measurements and is not locked, so automatic MLD/RVD MAE, RMSE, bias, limits of agreement, repeatability, failure rate and confidence intervals were not calculated.

The nine-phantom benchmark remains the only executed automatic geometry evidence. It reproduced the known low-contrast failure: 16 px width MAE while the existing adapter accepted all declared sites. This failure is preserved and blocks automatic grading without a stronger quality/abstention mechanism.
