# Severity browser and export verification

The Severity Assessment browser screen restores Case 60 with three candidates and correctly reports no reviewed measurements and no active grading protocol. It does not manufacture a category. Existing JSON/CSV/PDF/Evidence ZIP tests and browser evidence verify persistence, identifiers, hashes, access denial and immutable report snapshots.

The new pilot is intentionally not imported into the application because it contains no human measurements and is not locked. A new severity export cannot be generated honestly until a reviewer completes the worksheet and the guide approves a protocol. Browser/export integrity is verified; independent severity content remains unavailable.
