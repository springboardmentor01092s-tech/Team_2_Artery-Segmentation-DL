# Independent measurement protocol

Use a frozen image/frame/lesion list and a reviewer or separate method blinded to CoroVision outputs. Record original coordinates for the minimum and reference cross-sections, MLD, RVD, units, calibration evidence, reference rule, method/version, reviewer ID, quality and exclusion reason. Lock reference rows and hash their files before joining to predictions. Require exact frame and lesion pairing. Report the eligible denominator, exclusions, MAE, RMSE, bias and limits of agreement with patient-level grouping. Report any research-reference agreement separately from expert QCA agreement.

Use `SEVERITY_REFERENCE_COHORT_TEMPLATE.csv` as the collection schema. Each source image requires a SHA-256 digest. A millimetre row requires calibration provenance; otherwise retain original-image `source_px`. Set `independent_of_corovision=true` only when neither the locations nor diameters were generated from CoroVision predictions. Freeze and hash the completed CSV before any join with predictions. The validator in `backend/app/severity_reference.py` rejects missing fields, circular rows, ineligible quality status, invalid hashes, duplicate lesion identities, unsupported units and inconsistent diameters.
