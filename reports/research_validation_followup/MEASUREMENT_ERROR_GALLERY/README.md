# Measurement error gallery

No real-image error examples are available because no locked independent references exist.

Current controlled failure modes to preserve when the gallery is populated:

- low contrast: 16 px width MAE and 16.67 percentage-point narrowing MAE;
- boundary perturbation: 1.94 px width MAE and 4.73 percentage-point narrowing shift;
- branch-adjacent site: excluded from the original seven-phantom eligible set;
- overlap/ambiguous vessel geometry: withhold measurement;
- taper and curvature: retain exact site and cross-section evidence.

Future gallery entries must include original image hash, lesion/reference coordinates, independent overlay, CoroVision overlay, signed errors, quality decision and exclusion/abstention status. Do not add patient-identifying images or prediction-only examples labelled as reference errors.
